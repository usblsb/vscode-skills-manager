# Reglas del Proyecto

Coloca aquí tus reglas específicas para este proyecto.

## Uso

1. Crea archivos `.md`, `.json` o `.txt` con tus reglas
2. Click derecho sobre el archivo → **Add Rules: Aplicar a LLM**
3. Selecciona el LLM destino (Cursor, Roo, Cline, etc.)

## Notas

- Las reglas de esta carpeta solo aplican a este proyecto
- Para reglas que persistan entre proyectos, usa **Reglas Globales**
